# 隐私政策（Privacy Policy）

最后更新：2026-11-26 · 适用版本：KShell v0.0.4

KShell 的隐私设计只有一条原则：**零收集**。本软件没有自建服务器、没有账号体系、没有崩溃收集 SDK、没有广告和分析组件。你能看到的每一个功能都在你的设备上完成。

## 1. 我们收集哪些个人信息

**无。** 本软件不向开发者或任何第三方传输、上报任何个人信息或使用数据。

## 2. 本地存储的数据（永不离开你的设备）

| 数据 | 内容 | 存储方式 |
|---|---|---|
| 机器列表 | 已配对桌面端的名称、地址、配对信息、收藏与排序。配对信息包括 Kimi Code 设备标识与来源参数、ZCode 中继会话标识或旧版配对凭据 | AES 加密（MMKV `zshellSecure`），密钥由 Android Keystore 托管 |
| 应用锁与偏好设置 | 锁定方式、PBKDF2 验证器（盐 + 哈希）、失败次数及等待时间、通知/更新/登录保留开关与法律同意记录 | 同上 |
| 网页登录数据 | Kimi Code 和 ZCode 的登录 Cookie 与站点数据，同源机器共用 | 系统 WebView 保管；默认跨重启保留（可关闭），可在应用内一键清除并卸载在线会话 |
| 连接诊断 | 最近 200 条连接事件（不含配对密钥）；失败或超时时可以复制当次连接的耗时、状态和错误码摘要 | 本机非加密本地存储（MMKV `zshellDiag`），仅保存于本机，复制需用户主动触发 |
| 下载记录与外观偏好 | 应用内发起的更新包下载元数据（文件名、状态、校验摘要等）、深色模式与最近任务遮罩开关 | 本机私有 SharedPreferences（`zshell_downloads` 等），不含凭据 |

应用已禁用 Android 云备份与 Android 12+ 设备间换机数据迁移（`allowBackup="false"`、`fullBackupContent="false"`、`dataExtractionRules` 全域排除）。卸载应用或清除应用数据即可**彻底删除**应用内部全部数据（公共下载目录与用户导出的备份文件由用户自行管理）。

## 3. 权限用途说明

| 权限 | 用途 | 说明 |
|---|---|---|
| 相机（CAMERA） | 扫描桌面端配对二维码 | 仅取景识别，不拍照、不录像、不保存任何图像 |
| 生物识别（USE_BIOMETRIC） | 应用锁的指纹 / 人脸验证 | 仅调用系统本机验证，本软件不接触、不存储生物特征数据 |
| 照片访问 | 「从相册选择二维码图片」功能 | 仅在你主动选图时读取所选单张图片，识别完成即丢弃，不访问相册其他内容 |
| 网络（INTERNET） | 打开官方控制台与授权登录页、下载用户选取的文件、检查和下载 KShell 更新 | 控制台及登录仅使用官方 HTTPS 域名（`code-rc.kimi.com`、`code-rc.kimi.ai`、`auth.kimi.com`、`auth.kimi.ai`、`zcode.z.ai`、`zcode.chatglm.site` 等官方登录域），账号登录由官方页面处理。KShell 通过 GitHub Releases（`api.github.com` / `github.com`）检查并下载自身更新，可在设置关闭自动检查 |
| 通知（POST_NOTIFICATIONS） | 断线、会话被其他设备接管、等待批准、更新发现及下载暂停/超时取消提醒 | 由设备本机发出，可在设置中关闭或配置免打扰时段 |
| 安装应用（REQUEST_INSTALL_PACKAGES） | 应用内更新 | 更新包下载完成后先复制到应用私有缓存校验包名、签名证书（及官方 SHA-256 摘要，如有），通过后交由系统安装器安装，是否安装始终由你确认 |

### 本地附加数据

- 配对备份：由用户设置的口令加密（ZSBK2：PBKDF2-HMAC-SHA256 600,000 次迭代 + Encrypt-then-MAC，严格 Base64 校验），应用不保存口令。已导出的文件由用户管理

## 5. 数据安全

- 配对凭据使用 AES 加密存储，密钥存放于 Android Keystore，且启用应用锁时在解锁完成前不解密加载机器列表；
- 应用锁（生物识别 / 图案 / 密码）防止他人打开本应用查看或使用已保存的凭据，锁屏与备份口令/密文界面强制禁止截屏与录屏（`FLAG_SECURE`），锁屏时自动关闭弹窗并清空内存中的备份密文；
- 应用锁验证使用 PBKDF2-HMAC-SHA256（新设置默认 100,000 次迭代 + 随机盐 + 常数时间比较；兼容既有已保存验证器）并带失败退避冷却，不存储明文密码或图案；
- 请知悉：远程会话内容经由官方中继服务传输（见 [DISCLAIMER.md](./DISCLAIMER.md) 第 5 条），该环节不在本软件控制范围内。
