# 隐私政策（Privacy Policy）

最后更新：2026-11-20 · 适用版本：KShell v0.0.1.24

KShell 的隐私设计只有一条原则：**零收集**。本软件没有自建服务器、没有账号体系、没有崩溃收集 SDK、没有广告和分析组件。你能看到的每一个功能都在你的设备上完成。

## 1. 我们收集哪些个人信息

**无。** 本软件不向开发者或任何第三方传输、上报任何个人信息或使用数据。

## 2. 本地存储的数据（永不离开你的设备）

| 数据 | 内容 | 存储方式 |
|---|---|---|
| 机器列表 | 已配对桌面端的名称、地址、配对信息、收藏与排序。配对信息包括 Kimi Code 设备标识与来源参数、ZCode 中继会话标识或旧版配对凭据 | AES 加密（MMKV），密钥由 Android Keystore 托管 |
| 应用锁设置 | 锁定方式、PBKDF2 验证器（盐 + 哈希）、失败次数及等待时间 | 同上 |
| 网页登录数据 | Kimi Code 和 ZCode 的登录 Cookie 与站点数据，同源机器共用 | 系统 WebView 保管；默认跨重启保留（可关闭），可在应用内清除 |
| 连接诊断 | 最近 200 条连接事件；失败或超时时可以复制当次连接的耗时、状态和错误码摘要 | 时间线仅保存在本机。复制需用户主动触发 |

卸载应用或清除应用数据即可**彻底删除**以上全部数据。

## 3. 权限用途说明

| 权限 | 用途 | 说明 |
|---|---|---|
| 相机（CAMERA） | 扫描桌面端配对二维码 | 仅取景识别，不拍照、不录像、不保存任何图像 |
| 生物识别（USE_BIOMETIC） | 应用锁的指纹 / 人脸验证 | 仅调用系统本机验证，本软件不接触、不存储生物特征数据 |
| 照片访问 | 「从相册选择二维码图片」功能 | 仅在你主动选图时读取所选单张图片，识别完成即丢弃，不访问相册其他内容 |
| 网络（INTERNET） | 打开官方控制台、下载用户选取的文件、检查和下载 KShell 更新 | 控制台使用 code-rc.kimi.com、code-rc.kimi.ai、zcode.z.ai 或 zcode.chatglm.site，账号登录由官方页面处理。KShell 通过 GitHub Releases 检查自身更新，可在设置关闭自动检查 |
| 通知（POST_NOTIFICATIONS） | 断线、会话被其他设备接管、等待批准及版本更新提醒 | 由设备本机发出，可在设置中关闭 |
| 安装应用（REQUEST_INSTALL_PACKAGES） | 应用内更新 | 下载完成后交系统安装器安装，是否安装始终由你确认 |

## 4. 第三方组件

以下开源组件均为**本地功能实现**，不进行任何数据上报：

| 组件 | 用途 |
|---|---|
| react-native / react-native-webview | 应用框架与控制台容器 |
| react-native-camera-kit | 相机扫码 |
| react-native-image-picker | 相册选图 |
| react-native-mmkv-storage | 加密本地存储 |
| react-native-biometrics | 系统生物识别 |
| jsQR / jpeg-js / pako | 二维码图片识别（纯本地解码） |

应用内更新包通过系统 DownloadManager 保存到应用专用目录。控制台内主动触发的文件下载通过系统 DownloadManager 写入公共下载目录，可在「下载管理」查看、打开与删除。公共下载文件由用户管理。应用内法律文本（v10）与本文件同步维护。

### 本地附加数据

- 配对备份：由用户设置的口令加密（PBKDF2-HMAC-SHA256 派生密钥），应用不保存口令。已导出的文件由用户管理

## 5. 数据安全

- 配对凭据使用 AES 加密存储，密钥存放于 Android Keystore，无法在未 root 且未解锁的设备上被读取；
- 应用锁（生物识别 / 图案 / 密码）防止他人打开本应用查看或使用已保存的凭据；
- 应用锁验证使用 PBKDF2-HMAC-SHA256（20000 次迭代 + 随机盐），不存储明文密码或图案；
- 请知悉：远程会话内容经由官方中继服务传输（见 [DISCLAIMER.md](./DISCLAIMER.md) 第 5 条），该环节不在本软件控制范围内。

## 7. 政策变更

政策如有重大变更，将随版本发布在本文件更新。继续使用即表示接受更新后的政策。
